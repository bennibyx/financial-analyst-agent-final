GUIDANCE CLASSIFICATION RULES:
1. Extract guidance only when management explicitly provides a forward-looking expectation, target, or forecast for a financial or operating metric, such as revenue, EPS, profit, or margin.
2. Keep reported historical or current-period results in metrics, not guidance.
3. Do not classify contractual obligations, lease commitments, debt maturities, or other scheduled payments as financial guidance merely because they refer to the future. Extract them as guidance only if management explicitly presents them as a forecast or target for a financial or operating metric.
4. Preserve the exact value, unit, and future period stated in the source. Do not invent a period or convert units without updating the unit label.
5. If no qualifying guidance is stated, return an empty guidance list.
RISK CLASSIFICATION RULES:
1. Extract a risk only when the source explicitly identifies a risk factor, threat, uncertainty, exposure, or potential adverse impact.
2. Do not classify lease payments, contractual obligations, scheduled debt repayments, or debt maturities as risks solely because they are future obligations.
3. Do not infer that an obligation is a risk just because it could affect cash flow. The source must support the risk interpretation.
4. If no qualifying risk is identified, return an empty risks list.
5. For a qualifying risk, use Unknown severity unless the source explicitly supports High, Medium, or Low.
METRIC CLASSIFICATION RULE:
Do not extract lease payments, contractual obligations, scheduled debt repayments, or debt maturities as financial performance metrics solely because they contain a monetary value or future date. Extract metrics only when the source supports them as financial or operating measures, such as revenue, net income, expenses, cash, debt balances, margins, or cash flow. A reported debt balance may be a metric, but a scheduled repayment obligation is not automatically a metric.   
GUIDANCE UNIT PRESERVATION:
The Guidance schema has no separate unit field. Therefore, include the unit in the guidance value string. For example, if the source says "$120 million", return "120 million USD"; if it says "38%", return "38%". Never return only the number when the source provides a unit. Preserve the stated period and numeric scale.
